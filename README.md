# geo-iptv
Georgian channels for free - completely legal.
ქართული არხები უფასოდ. 100% ლეგალური.

# How to use -- გამოყენება
Get a m3u8 player application like VLC /// ამისათვის დაგჭირდებათ M3U8 პლეიერის აპლიკაცია, მაგალითად VLC

Point your player at https://github.com/AnikuHere/geo-iptv/blob/main/georgia_channels.m3u /// თქვენი პლეირე დააყენეთ წყარო ამ ლინკზე : https://github.com/AnikuHere/geo-iptv/blob/main/georgia_channels.m3u

# Contribution - კონტრიბუცია
If you want to // თუ გინდათ რომ:

- Add your channel // დაამატოთ საკუთარი არხი
- Add someone elses channel // დაამატოთ სხვისი არხი

Please remember that // დაიმახსოვრეთ რომ:

- The channel you are adding must be in Georgian or must be based in Georgia // არხი უნდა იყოს დაფუძნებული საქართველოში ან უნდა იყოს ქართულ ენაზე
- The channel you are adding must already be legally available on the internet. This does not count paid IPTV services and their CDN's. // არხოი უნდა იყოს უფასოდ ხელმისაწვდომი ონლაინ ინტერნეტზე. ამ სიაში არ შედის გადასახდელი ინტერნეტ სატელევიზიო სერვისები და მათი სერვერები რაზეც არხებია შენახული (CGC, Magti, SilkNet, ა.შ.)

If you add your own channel, please do not add adult or illegal material or your channel will be banned from this M3U8 playlist and will not be available for re-adding. // თუ ამატებთ საკუთარ არხს, არ აჩვენოთ პორნოგრაფია ან არალეგალური მატერიალი, სხვა შემთხვევაში კი თქვენი არხი წაიშლება სიიდან და აღარ დაემატება.
